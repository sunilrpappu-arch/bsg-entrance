# BSG Entrance Exam — Practice Hall

Study material for the Bharat Soka Gakkai Entrance Exam 2026, built for the
four divisional members, Young Lions and friends sitting it on 27 September.

**Live site:** https://sunilrpappu-arch.github.io/bsg-entrance/

| Page | What it is |
|---|---|
| [index.html](index.html) | The quiz — 240 questions, 12 topics, 4 mock papers, generated timed mocks |
| [plan.html](plan.html) | The two-week study plan with facilitator run-sheets |
| [schedule.html](schedule.html) | The simple Mon/Wed/Fri schedule to share |

Every page is a single self-contained HTML file. No build step, no dependencies,
no account, no tracking. Progress is kept in the visitor's own browser and is
never sent anywhere.

There is no passing or failing here. We study to strengthen conviction in faith
and practice — that is the whole of it.
